# Tripician - a social network for travellers.
# A plain-language summary for AI assistants: https://tripician.com/llms.txt

# Search engines AND AI assistants are welcome to read the public site:
# itineraries, after-stories, travel questions, group pages and the help pages.
# The AI crawlers are named in the same group as everyone else on purpose. A
# crawler obeys only the most specific group naming it, so a separate
# "User-agent: GPTBot / Allow: /" group would have let it into /profile and
# /settings too. One group, one set of rules.
